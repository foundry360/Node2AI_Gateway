# Node2AI Blockchain Production Setup Guide

This guide provides step-by-step instructions for setting up Hyperledger Fabric blockchain for Node2AI in a production environment.

## Prerequisites

### Required Software

1. **Node.js** (v18 or later)

   ```bash
   node --version  # Should be v18+
   ```

2. **Package Manager** (pnpm or npm)

   ```bash
   pnpm --version  # or npm --version
   ```

3. **Hyperledger Fabric** (v2.5 or later)
   - Test Network: For development/testing
   - Production Network: For production deployments

4. **OpenSSL** (for key generation)
   ```bash
   openssl version
   ```

### Required Infrastructure

- Hyperledger Fabric network (running and accessible)
- Connection profile JSON file
- Network channel created (default: `node2aichannel`)
- Chaincode deployed (default: `node2ai`)

## Quick Start

### Automated Setup

Run the production setup script:

```bash
cd /path/to/Node2/blockchain
./setup-production.sh
```

This script will:

1. Check prerequisites
2. Create wallet directory
3. Enroll admin identity
4. Register and enroll app user
5. Generate signing keys
6. Test connection

### Manual Setup

If you prefer manual setup, follow the [Detailed Setup](#detailed-setup) section below.

## Detailed Setup

### Step 1: Configure Environment Variables

Create or update `apps/api/.env.local`:

```bash
# Enable blockchain
BLOCKCHAIN_ENABLED=true

# Connection profile path (absolute path recommended for production)
BLOCKCHAIN_CONNECTION_PROFILE=/path/to/your/connection-profile.json

# Wallet path (defaults to ./blockchain/wallet if not set)
BLOCKCHAIN_WALLET_PATH=/secure/path/to/wallet

# Channel name
BLOCKCHAIN_CHANNEL_NAME=node2aichannel

# Chaincode name
BLOCKCHAIN_CHAINCODE_NAME=node2ai

# Organization MSP
BLOCKCHAIN_ORG_MSP=Org1MSP

# User ID for blockchain operations
BLOCKCHAIN_USER_ID=appUser

# Signing key (generate with: openssl rand -base64 32)
BLOCKCHAIN_SIGNING_KEY=your-generated-signing-key-here
```

### Step 2: Set Up Hyperledger Fabric Network

#### Option A: Test Network (Development)

```bash
# Navigate to Fabric samples
cd ~/hyperledger/fabric-samples/test-network

# Start network with CA
./network.sh up createChannel -c node2aichannel -ca

# Verify network is running
docker ps | grep fabric
```

#### Option B: Production Network

For production, you'll need:

1. **Network Setup**: Use your organization's Fabric network infrastructure
2. **Connection Profile**: Generated by your network administrator
3. **Channel**: Join or create the channel for Node2AI
4. **Chaincode**: Deploy the chaincode from `blockchain/chaincode/`

### Step 3: Create Connection Profile

#### For Test Network

The connection profile is automatically generated at:

```
~/hyperledger/fabric-samples/test-network/organizations/peerOrganizations/org1.example.com/connection-org1.json
```

#### For Production Network

Your network administrator should provide:

- Connection profile JSON file
- Channel name
- Chaincode name
- Organization MSP ID

### Step 4: Deploy Chaincode

#### Build Chaincode

```bash
cd blockchain/chaincode
go mod tidy
go build
```

#### Deploy to Test Network

```bash
cd ~/hyperledger/fabric-samples/test-network

# Package chaincode
peer lifecycle chaincode package node2ai.tar.gz \
  --path ../Node2/blockchain/chaincode \
  --lang golang \
  --label node2ai_1.0

# Follow Hyperledger Fabric documentation for chaincode deployment
```

#### Deploy to Production Network

Follow your organization's chaincode deployment procedures.

### Step 5: Set Up Wallet and Identities

#### Enroll Admin

```bash
cd blockchain
node -r ts-node/register sdk/enroll-admin.ts
```

#### Register and Enroll App User

```bash
cd blockchain
node -r ts-node/register sdk/register-user.ts
```

**Note**: If user registration fails, you may need to register manually via CA CLI:

```bash
# From test-network directory
docker exec -it ca_org1 fabric-ca-client register \
  --id.name appUser \
  --id.secret appUserpw \
  --id.type client \
  --id.affiliation org1.department1
```

Then enroll:

```bash
cd blockchain
node -r ts-node/register sdk/register-user.ts
```

### Step 6: Generate Signing Keys

Generate a secure signing key:

```bash
openssl rand -base64 32
```

Add to `apps/api/.env.local`:

```bash
BLOCKCHAIN_SIGNING_KEY=<generated-key>
```

### Step 7: Verify Setup

#### Check Wallet

```bash
ls -la blockchain/wallet/
# Should show: admin.id, appUser.id, and appUser/ directory
```

#### Test Connection

```bash
cd blockchain
node -r ts-node/register test-integration.ts
```

#### Check API Server Logs

Start the API server and check for:

```
Blockchain configuration:
  Enabled: true
  Channel: node2aichannel
  Chaincode: node2ai
  ...
Successfully connected to Fabric network
```

## Production Configuration

### Security Considerations

1. **Wallet Security**
   - Store wallet in secure location
   - Use file system permissions: `chmod 700 blockchain/wallet`
   - Back up wallet securely (encrypted)

2. **Connection Profile**
   - Use absolute paths
   - Restrict file permissions: `chmod 600 connection-profile.json`
   - Store in secure location

3. **Signing Keys**
   - Never commit keys to version control
   - Rotate keys periodically
   - Use key management system in production

4. **Network Security**
   - Use TLS for all connections
   - Implement proper access controls
   - Monitor network activity

### Performance Optimization

1. **Connection Pooling**: Configure gateway connection pool
2. **Async Operations**: Blockchain operations are already async
3. **Batching**: Consider batching multiple transactions
4. **Caching**: Cache frequently queried records

### Monitoring

Monitor the following:

1. **Connection Status**: Check `isBlockchainConnected()`
2. **Transaction Success Rate**: Monitor audit log records
3. **Latency**: Track blockchain operation times
4. **Errors**: Monitor blockchain service errors

## Troubleshooting

### Connection Issues

**Problem**: "Not connected to blockchain network"

**Solutions**:

1. Verify Fabric network is running: `docker ps | grep fabric`
2. Check connection profile path is correct
3. Verify wallet contains required identities
4. Check network connectivity to Fabric peers

### Identity Issues

**Problem**: "User identity not found in wallet"

**Solutions**:

1. Run enrollment scripts:
   ```bash
   node -r ts-node/register sdk/enroll-admin.ts
   node -r ts-node/register sdk/register-user.ts
   ```
2. Verify wallet directory permissions
3. Check wallet path in configuration

### Chaincode Issues

**Problem**: "Chaincode not found"

**Solutions**:

1. Verify chaincode is deployed: Check network logs
2. Verify chaincode name matches configuration
3. Check channel name is correct

### Performance Issues

**Problem**: Slow blockchain operations

**Solutions**:

1. Check network latency
2. Verify Fabric network is properly configured
3. Consider using localhost discovery for test network
4. Optimize chaincode queries
